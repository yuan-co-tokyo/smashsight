# お手本との同期比較

動画を「お手本」「自分の動画」としてアップロードし、`/compare` で各1本を選びます。既存動画はマイグレーションで `practice`（自分の動画）になります。種別変更UIはないため、お手本はその種別でアップロードしてください。

選択は `?model=<uuid>&target=<uuid>`、左右反転は `flipModel=0|1&flipTarget=0|1` に保持します。URLを再読み込みしても復元しますが、アクセスできるのは動画所有者本人だけです。他人・未完了・種別違い・不正IDはサーバー側で404になります。

## 操作

各パネルの個別シークでインパクト等を選び「現在位置を基準点にする」を押します。設定はこの画面内のメモリだけで保持し、再読み込みでは0秒へ戻ります。「基準点へ戻る」で両方を揃え、「同期再生」で再生します。速度は0.25/0.5/1倍、コマ送りはソースのフレームレートによらず1/30秒です。個別シーク・基準点設定・コマ送り時には両方を停止します。音声はミュートです。

同期は左動画の `currentTime - 左基準点` を相対時刻とし、右を `右基準点 + 相対時刻` に合わせます。再生可能区間は2本の区間の共通部分でクランプします。右のずれが120msを超えたらシーク補正し、片方の終端で両方停止します。フレーム単位で完全に同時表示する保証はありません。バッファリング時も両方止め、ユーザーに再生操作を促します。

## 骨格の負荷と反転

T3のプレイヤーを再利用し、各動画に独立したWorkerとモデルを持たせます。推論の共有ゲートにより同時推論は1件だけにし、待っている相手を優先します。各動画は最大5fps、長辺640pxです。動画は待たずに再生を続け、古い骨格は表示しません。低性能端末では再生中の骨格が欠けるため、一時停止して確認してください。2モデル分のメモリは使用します。初期化は並列になり得ます。

映像とcanvasを共通の親要素で `scaleX(-1)` にするため、一緒に反転します。操作UIは反転しません。骨格数値の比較や解析結果保存は行いません。

## 検収手順

1. leaderが `pnpm db:migrate` を適用し、buildする。既存動画の種別がpracticeであることを確認。
2. お手本と自分の動画をアップロード。種別ごとの一覧・詳細から比較への導線を確認。
3. `/compare` で2本選択し、URL再読み込みで選択を復元。不正ID・他人ID・未完了・種別違いを指定して404を確認。
4. 異なる基準点を設定し、戻る・再生・停止・前後コマ送り・速度3段階を確認。長さの違う動画で片方終端時に両方止まることを確認。
5. 個別反転とURL復元を確認。骨格ONで映像と骨格が一緒に反転することを確認。
6. 狭い画面で上下配置、iPhone実機で共通再生ボタンから2本再生、前後シーク、背景移動、バッファリングと復帰操作を確認。

iOSのデコード・再生許可、2モデルのメモリ消費、発熱は実機で確認が必要です。骨格の非対応・CORS失敗時は通常再生へ縮退します。署名URL期限切れ時はページを再読み込みしてください。

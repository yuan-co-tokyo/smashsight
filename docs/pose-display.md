# ブラウザ内の骨格表示

`/videos/[id]` の「骨格表示」をオンにすると、MediaPipe Pose Landmarker full / CPU / 1人で表示中のフレームを解析します。最大10fps、長辺640px、Workerへの推論要求は1件ずつです。IMAGEモードで各フレームを独立に推論し、逆向きシーク時に過去の追跡状態を引き継ぎません。低性能端末では更新頻度が下がります。

動画時刻と33ランドマークを `PoseSample` と `poseSample()` で分離し、`startPosePlayer` の `onSample` から取得できます。時系列の蓄積、保存、角度計算、比較は行いません。シーク世代が古い結果や動画時刻から150ms以上ずれた結果は描画せず、過去の骨格を残しません。

## 資産

`pnpm pose:sync-assets` は固定バージョン `@mediapipe/tasks-vision@1.0.1` からJS/WASMを同期し、Google公式の full float16 v1 モデルを取得します。取得元・SHA-256は `lib/pose/assets.json` に固定しています。全資産は `public/pose-assets` に配置し、ブラウザは同一オリジンだけにアクセスします。モデルは同期時とWorker初期化時にSHA-256を検証します。

`pnpm dev` / `pnpm build` の前処理で同期します。検証済みモデルがあれば再取得しません。ネットワークが必要な初回取得はleader側で行ってください。生成物はgitignore対象です。

## ブラウザ確認

1. localhostまたはHTTPSでログインし、全身の映る動画詳細を開きます。通常再生後に骨格表示をオンにします。
2. 初期化中も再生でき、モデル準備後に緑の点と線が人物に重なることを確認します。NetworkタブでJS/WASM/モデルが同一オリジンであることを確認します。
3. 再生・一時停止・前後シーク・連続シーク、縦動画・横動画・画面回転・リサイズで位置と時刻の一致を確認します。回転はvideoのデコード済み寸法を使用し、独自に二重回転しません。
4. オフにすると骨格が消えること、オンに戻すと再初期化すること、別画面へ移動するとWorkerが終了することを確認します。
5. モデル/WASM取得をブロックし、エラー案内と通常再生を確認します。S3のCORSを外した場合も骨格なし再生に切り替わることを確認します。
6. iPhone Safari/Chrome実機でネイティブ再生ボタンをタップしてからオンにします。背景へ移動すると解析が止まり、戻っても勝手に再開しないことを確認します。

## 制約

HTTPS/localhost、Worker、OffscreenCanvas、createImageBitmapが必要です。非対応時は通常再生へ縮退します。初期化60秒・各フレーム15秒でタイムアウトしWorkerを終了します。
iOSのデコード開始はユーザーによる再生操作が必要な場合があります。非表示videoの自動再生や全編の連続シークは行いません。全画面/PiPは動画のみです。ブラウザ/コーデック依存の回転・フレーム取得や発熱は実機確認が必要です。
再生中に推論が150ms以上遅れる端末では骨格が出にくくなることがあります。一時停止したフレームは推論終了後に描画できます。人物の欠損や遮蔽では一部または全部の骨格が表示されません。複数人が映る場合、対象人物の選択は保証しません。

S3署名URLは5分間有効です。期限切れ・動画形式の非対応はページ再読み込み等が必要です。CORS設定は [aws-setup.md](aws-setup.md) を参照してください。
